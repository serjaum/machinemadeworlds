An AI agent is a language model wrapped in a perceive-decide-act loop that calls tools, reads what comes back, and keeps going until a stop rule fires or a human gate asks for approval.

How it works

Each turn starts with the model reading the goal, the conversation so far, and whatever the last tool returned, then choosing the next action: answer, call a tool, or stop. The system prompt sets the role and the hard rules for the whole run, tools such as search, code execution, or document lookup extend what the model can touch, and inference produces each decision one token at a time. Memory for the loop often arrives as retrieved passages, the retrieval-augmented pattern that grounds each step in fresh evidence, matched by meaning through embeddings rather than keywords. Randomness per step stays under the builder's control through the temperature setting, kept low when the loop must behave the same way twice.

Autonomy is a dial, not a switch. A chatbot answers once per message and never acts between replies; a workflow runs a fixed sequence of model calls where each step is scripted in advance; an agent sits between and beyond them, choosing its own path through tools until the job is done. The widely used framing from Anthropic on building effective agents draws the same line: workflows orchestrate fixed paths while agents direct their own process and tool use. Builders slide the dial by choosing how many tools the loop can reach, how many turns it may take, and which actions need a person to sign off.

Every serious agent ships with explicit stop conditions: a maximum number of turns, a success test the model must satisfy before answering, and a human gate in front of irreversible actions such as sending messages, spending money, or changing shared data. Without these the loop can spin on a vague goal, retry a failing tool forever, or take a costly action nobody reviewed. Builders treat the stop rule and the approval gate as part of the definition, not decoration: narrow permissions, visible tool transcripts, and a person in the loop wherever the cost of being wrong exceeds the cost of asking.
