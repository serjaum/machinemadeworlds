Signal, not noise: five primary-source reads from September 22 and 23, each with a two-line note on why it matters for builders.

Security improvements for SSH

GitHub is removing RSA keys using SHA-1 and the older Diffie-Hellman key exchange from SSH, requiring new RSA keys to be at least 3072 bits, and adding a post-quantum key exchange option, with brownouts before final removal. Audit CI runners, deploy keys, and old clients now, and prefer Ed25519 keys so the brownouts pass unnoticed.

GPT-6 Sol and GPT-6 Luna land in Copilot

GitHub Copilot adds two more GPT-6 models next to Astra: Sol as the balanced choice for interactive and agentic coding, and Luna as the lightweight, lowest-cost option for smaller, faster tasks, rolling out gradually across editors, CLI, and mobile. Set your model policy now and route routine completions to Luna so the heavy models only burn budget where they earn it.

Read the full story at GitHub Changelog (September 22, 2026).

Claude Opus 5.5 arrives in Copilot

Anthropic's newest Opus model is available in Copilot for agentic coding and long-running tasks, resolving about as well as Opus 5 with far fewer steps and tokens, recovering quickly from multistep errors, and watermarking text outputs at no extra cost. Trial it on your longest agent runs first and compare step counts and token burn before changing team defaults.

Read the full story at GitHub Changelog (September 22, 2026).

Local sandboxing in the Copilot app

The Copilot app now offers per-project local sandboxing that bounds filesystem, network, and credential access for repository sessions, off by default and toggleable per session, with the shell failing closed when the OS cannot enforce the policy. Turn it on for every project where agents touch real checkouts so one stray command cannot reach secrets or the wider network.

Read the full story at GitHub Changelog (September 23, 2026).

Claude finds a CRISPR-like enzyme system

Anthropic's new life-sciences group let roughly 950 Claude agents search DNA databases for 21 hours, and one spotted a never-described enzyme system pairing a reverse transcriptase with an array of evenly spaced DNA repeats expressed as short RNAs, now shared as an early preprint with lab work ongoing. Study the pipeline shape, not just the biology: massive agent-led hypothesis generation with human lab validation is a template for discovery work in any data-rich field.
