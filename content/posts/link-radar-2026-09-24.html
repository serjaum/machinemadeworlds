Signal, not noise: five primary-source reads from September 22 to 24, each with a two-line note on why it matters for builders.

Proof of presence for high-impact actions

Enterprise Cloud can now demand a fresh re-authentication or multi-factor challenge before members take high-impact actions like creating tokens, editing webhooks, or changing security settings, starting as a public preview for managed-user enterprises on Entra ID single sign-on. Roll this out where stolen sessions or tokens would hurt most, since the check confirms a real person is acting right now instead of trusting a possibly hijacked session.

More ways to request and configure Copilot code reviews

Copilot code review now has a dedicated personal settings page on every plan plus an enterprise-wide default review effort, with automatic reviews for new pull requests, drafts, and pushes and a Lite or Balanced default effort. Set the team default once at the enterprise level and let repositories override only where they need deeper reviews, so review quality stops depending on each developer remembering to ask.

Read the full story at GitHub Changelog (September 23, 2026).

Node 20 is no longer available in GitHub Actions

GitHub Actions runners now use Node 24 for JavaScript actions and the temporary opt-out flag is gone, so action maintainers must ship with node24 and workflow users must upgrade to supporting releases. Audit your workflows and self-hosted fleets this week, especially macOS 13.4 or older and ARM32 runners, which the new runtime no longer supports.

Read the full story at GitHub Changelog (September 23, 2026).

OpenTelemetry in the GitHub Copilot app

The Copilot app now supports OpenTelemetry configuration through enterprise-managed settings, letting administrators stream agent activity data into their own monitoring tools. Wire this into your existing dashboards before agent usage grows, so model, tool, and session behavior stays observable instead of becoming a black box.

Read the full story at GitHub Changelog (September 22, 2026).

Faster C++ code intelligence with whole codebase indexing

Copilot CLI now indexes whole C++ codebases up front, building a persistent symbol index from project compilation info so definitions, references, and symbol search resolve without rediscovering project structure on every request. Expect a one-time indexing cost in time and memory on large repositories, then faster navigation; restart the session after toggling the setting.
