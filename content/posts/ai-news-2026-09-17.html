Builders get a frontier agent that works inside real software, a giant open-weights alternative, and office tools that decide for themselves whether to chat or do the task, alongside two plays for AI that never leaves your hardware and a way to run research papers as tools. OpenAI's new flagship operates browsers, spreadsheets, and engineering apps end to end, while Shanghai AI Lab answers with MIT-licensed weights you can self-host. Here are seven stories worth your time, each summarized in our own words with a link to the original reporting.

OpenAI launches GPT-6 Astra as an agentic flagship

OpenAI released GPT-6 Astra as a frontier model built to carry out multistep computer work rather than just answer prompts. The company describes it filling forms, updating CRM records, organizing calendars, researching the web, drafting documents and mail, manipulating spreadsheets, analyzing data in Python notebooks, building and testing sites, operating engineering tools, and installing software. Reported scores include 72.6 percent on an offline OSWorld 2.0 subset in about 40 minutes per task versus 65.7 percent in 75 minutes for the prior model, plus 97.6 percent on FrontierMath Tier 4 v2 and 95.9 percent on BenchCAD. The API model name is gpt-6-astra, rolling out first to enterprise Daybreak customers, then Plus, Pro, Business, Enterprise, the API, AWS Bedrock, and Microsoft Azure.

Astra becomes the first model rated Critical for cyber capability

OpenAI classified Astra at the Critical level of its Preparedness Framework for cybersecurity, the first model to reach that tier, meaning it can find unknown vulnerabilities and build exploit chains across hardened systems with tools and without continuous guidance. The company reports 100 percent on ExploitBench and says two previously unknown flaws found during evaluation were disclosed to maintainers. Advanced offensive capability is gated to trusted defenders through Daybreak Blue, with broader access under tighter restriction and monitoring. Microsoft made the model generally available in Foundry Models the same day, listing $10 per million input and $50 per million output tokens on short context, rising to $20 and $75 on long context, with cached input at a tenth of input rate.

Read the full story at InfoQ (September 17, 2026).

Shanghai AI Lab drops Atria Dawn, a 744B open-weight agentic model under MIT

Shanghai AI Lab quietly published Atria Dawn Preview, a 744-billion-parameter mixture-of-experts agentic model with roughly 40 billion parameters active per token, built on the GLM-5.2 base and further trained for long tool-using research and engineering loops. Weights appeared on GitHub and Hugging Face in FP8 and BF16 days before the 143-author technical paper, under an MIT licence allowing unrestricted commercial use, modification, and redistribution. The lab also runs a hosted API compatible with Chat Completions, Messages, and Responses formats so existing agent stacks can switch endpoints. Caveats for builders: a 256,000-token text-only context, no independent benchmark reproduction yet, and self-hosting footprints around 756 GB to 1.5 TB.

Read the full story at GenAI Daily (September 17, 2026).

Anthropic merges Cowork into Claude and ships Docs and Slides

Anthropic folded Cowork into the main Claude app so the assistant itself decides whether a request needs a chat reply or a longer agentic task, and added Claude Docs and Claude Slides editors in beta for paid plans. Documents and decks created by Claude can be edited directly with collaborators, with export paths into Word and other office formats, and Claude Design moves into the main conversation while Claude Code stays separate. Pro and Max subscribers get the change first across web, desktop, and mobile, with Team, Free, and enterprise admins following on at least 30 days notice. The move mirrors OpenAI's July consolidation of ChatGPT and Codex into one desktop app with a Work mode.

Read the full story at The Next Web (September 17, 2026).

Perplexity brings its fully on-device agent to Windows RTX PCs

Perplexity shipped Portable Computer for Windows through the Microsoft Store app, running the model, harness, orchestrator, and scheduler entirely on the device for Pro and Max subscribers. The default local model is Qwen 3.8 27B post-trained for the Computer harness and optimized for RTX GPUs, alongside a PPLX 27B variant, with Nemotron 3.5 Lightning 30B listed as coming soon and local dictation via Nemotron 3.5 ASR. Connectors cover Outlook, OneDrive, Word, Drive, Gmail, Slack, and GitHub, plus local MCP servers to desktop apps, with code execution in isolated sandboxes including the SPACE sandbox. Local work burns no Computer credits, cloud escalation asks permission first, and the floor is 24 GB of VRAM, which excludes most consumer PCs.

Read the full story at BitsMinds (September 16, 2026).

LM-Kit One packages private models, search, and agents as one server

LM-Kit released LM-Kit One, a private AI application server for Windows, Linux, and macOS that bundles model execution, document processing, retrieval, agents, and operational controls into one versioned product. Teams can extract structured data from scans and PDFs, answer from internal collections with source references, and run agents under explicit tool permissions, all on infrastructure they control. A fresh install listens locally only, needs no account, key, or activation, and runs fully offline once models are provisioned, with telemetry export off unless enabled. Apps integrate over native REST, OpenAI-, Anthropic-, and Ollama-compatible endpoints, or MCP, scaling from one machine to nodes behind a load balancer.

Read the full story at LM-Kit (September 15, 2026).

Stanford's Paper2Agent turns papers into runnable MCP servers

Stanford researchers published Paper2Agent in Nature, a pipeline that converts a paper plus its codebase into a Model Context Protocol server any MCP-compatible agent such as Claude Code can drive in natural language. The pitch is a virtual corresponding author: instead of cloning, installing, and debugging research code, an agent calls the paper's methods as tools. The code is MIT-licensed with install paths as skills for Claude Code or Codex, prebuilt AlphaGenome, Scanpy, and TISSUE servers on Hugging Face Spaces, and a hosted version. For builders it is a practical pattern for reproducing results and running published methods on new data without hand-wiring each repo.
