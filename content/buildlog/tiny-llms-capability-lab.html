The site gains a permanent capability lab for tiny language models at a new lab address, with a fixed six-task battery, a shared scoring rubric, per-model verdict pages, a model backlog, and a weekly routine, all rendered through the existing static page system with no new scripts.

Motivation

Findings about small models used to live scattered inside journal posts, with no fixed battery and no way to compare one model against another. The lab gives that work a permanent home: every model faces the same six tasks, including a Portuguese probe, and every verdict states what the model can do, where it breaks, and how to reproduce the run.

What changed

Three new addresses now render as full pages: the lab index with the capability matrix, the backlog, and the weekly routine, the methodology page with the six task definitions and the scoring rubric, and one page per evaluated model with its ship verdict, limits, and reproduction note. The footer navigation gains a lab link while the header stays exactly as it was. All five lab addresses join the sitemap, each carries its own canonical address plus social tags from the shared page renderer, and the journal feed stays untouched. Styling arrives as one additive rule set bound to existing semantic tokens, with matrix verdicts always shown as text plus symbol so nothing depends on color alone.

How it was done

After the hosting preflight and a fresh feature branch from the main line, development added three static templates following the existing information-page pattern, wired them through the deterministic builder with no new dependencies, and extended the footer and the sitemap list only. The matrix reuses the proven article-table idiom with a labelled scroll region, sticky row headers, and scoped headers, and every date carries a machine-readable time element. This log entry ships in the same change per the standing rule. One deviation from the design brief: the spec base carries no Metrics page or footer link, so the lab link lands after Build log instead of after Metrics; the header stays unchanged.
