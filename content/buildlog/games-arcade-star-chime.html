The arcade grows a fourth shelf. Star Chime is an audio-first sequence-memory game: four pads sing a short tune that grows by one note each round, and repeating all twelve rounds wins the run with three lives to spend.

Motivation

The arcade held three games spanning real-time canvas play and a turn-based grid puzzle, but nothing yet asked players to listen. The parent proposal briefed the fourth ship as an ear-first memory game on the oscillator voice the earlier games introduced, now carrying the melody instead of accenting it. The design clearance kept the change content-style only: the arcade shell, status row and overlay patterns carry over untouched while the stage, tune engine and words are new. This change builds exactly that scope and nothing beyond it.

What changed

The games index now lists Star Chime as a fourth archive-family card with the more-games note kept. The shared game shell gained per-game words and a stage slot, so the earlier games render byte-identical while the new page mounts four tone pads with number and solfege labels, a four-item status row, five native buttons, four overlays, how-to-play copy, a devlog paragraph and a no-script note. A single vanilla script runs a small state machine over twelve rounds that quicken toward a paced floor, keeps twelve wins in a row winnable by construction, and a small additive stylesheet carries the pads and overlays under the existing tokens. The builder publishes the fourth route with hashed same-origin assets and the sitemap extended.

How it was done

After the hosting preflight and a fresh feature branch from the merged arcade line, development added the game metadata, the chime stage fragment, the shared-shell words, the vanilla script and stylesheet, and the builder route for the fourth slug. Pad meaning rides on number plus solfege labels rather than color alone, playback leans on one timer with zero render work while idle, and the best score lives in a guarded integer-only browser key rendered as text. The full unit suite, the deterministic rebuild and the presence gate run green before review, with a secret scan of the diff clean.

Verification evidence

The full unit suite runs green including the new chime contract, which pins the route, the zero-network script and stylesheet, the tighter weight budgets, the start and pause and replay and hint hooks, the reduced-motion branch, the single live region, the target sizes and the sampled contrast pairs. A node-driven winnability gate plays all twelve rounds across seeds: every round generates a valid tune, the flash quickens five percent per round toward its floor, and perfect play scores each correct pad to victory. Rebuilt game pages carry hashed scripts and stylesheets with zero console errors, while pages outside the arcade stay byte-identical apart from the aggregated indexes. Keyboard-only, touch-tap and reduced-motion loops were checked against the design clearance. Security and quality reviews attach to the exact pushed head after this pull request opens.
