This PR ships Build Log v2 for the parent spec MAC-72: a CODEOWNERS file, a machine-readable buildlog schema with ordered pipeline stages and per-agent reasoning, and a data-driven pure HTML+CSS pipeline diagram cleared by the MAC-78 design assessment. It also migrates the three existing entries to the new schema and logs itself, per the standing always-log rule.

Motivation

The parent backfill issue (MAC-64) proved entries can reconstruct a shipment, but the old schema only kept free text: a pr string, a short commit and an agents list. MAC-72 asks for stages with verdicts, return loops, links and reasoning, and MAC-78 cleared a vertical pipeline-diagram component with strict acceptance criteria. This entry covers that whole change in the same PR, as MAC-64 requires.

What changed

Added CODEOWNERS at the repo root (* @serjaum). Extended scripts/build.py validation: pr is now an int (or null with no PR), plus pr_url, branch, merge_sha (full 40-char SHA, or null pre-merge with a reason in merge_note), an ordered stages array with PASS/BLOCK/FAIL/done/skipped verdicts, and a reasoning map. The builder renders a pipeline block from stages into each entry's trail div, and assets/site.css gained additive flow-* classes. Migrated all three existing entries to the new schema.

How it was done

After GitHub preflight and a fresh branch feat/buildlog-v2-pipeline from origin/main at 97683bb, DEV extended the validator (BLOCK/FAIL require rationale plus two return-loop entries; non-skipped stages require a SHA), added render_pipeline reusing the post.html and agent-trail pattern with short SHAs in code, and nested the block inside the existing .trail div. Full SHAs and PR numbers in the migrated entries were read from git history and the GitHub API, never invented; unevidenced agents are marked as such.

Verification evidence

New tests cover BLOCK-without-rationale, stage-without-SHA except skipped, missing return loops, pr_url/merge/reasoning rules, and diagram rendering for all verdict shapes through the ArticleMarkup gate. The full suite runs with python -m unittest discover -s tests, the build is byte-identical across rebuilds, scripts/check_buildlog_presence.py passes on this branch, and a secret scan of the diff is clean. SEC and QA reviews attach to the exact pushed head SHA after this PR opens.
