Privacy Policy for Segredo de Arquivo: what the TikTok auto-upload service handles, why, and your rights.

Effective September 7, 2026.

1. Who operates this service

This policy describes how the operator of Segredo de Arquivo handles information for the TikTok auto-upload service described on this site (forthcoming channel @segredodearquivo; no live channel linked here).

2. Data we handle

Only the data needed for authentication and uploading:

  • TikTok OAuth access and refresh tokens;
  • TikTok account handle;
  • Video files submitted for upload;
  • Minimal operational logs needed to run and troubleshoot the service.

3. Purpose - authentication and upload only

This data is used solely to authenticate with the TikTok API and to upload videos. It is not used for any other purpose.

4. Storage and security

Tokens and related data are stored encrypted. Tokens and secrets are never placed in source code or logs.

5. Retention

OAuth tokens are deleted when the TikTok connection is disconnected. Operational logs are kept only as long as needed for operation and troubleshooting and are rotated. Video files are kept only as long as needed to complete the upload.

6. Sharing - no sale; TikTok API only

We do not sell personal data and do not share it with third parties, except the TikTok API as required to authenticate and upload at your direction.
